# 文字卡牌对战游戏 — 设计文档

**日期：** 2026-05-27
**状态：** 设计完成
**Godot 版本：** 4.6.3-stable

---

## 1. 概述

### 1.1 游戏概念

一款以"填词造句"为核心玩法的 1v1 卡牌对战游戏。玩家与 AI 轮流构造句子，句子经由评分引擎转换为战斗力，先耗尽对方 HP 者获胜。

### 1.2 核心循环

```
抽牌 → 选牌(拖入造句槽) → 填词(受卡牌约束) → 评分(紊乱度×连击×修辞) → 战斗结算 → 局内事件 → 对手回合 → ...
```

### 1.3 与现有项目的关系

项目已存在 Godot 4.6 基础架构（Autoload 系统、卡牌资源、战斗场景、AI 框架）。本次改造保留 Autoload 模式及 Events/CardDatabase/TurnManager/BattleManager/AIController 骨架，重写所有游戏逻辑，UI 全面重建。

## 2. 卡牌系统

### 2.1 卡牌类型

| 类型 | 说明 |
|------|------|
| 填词牌 | 带约束的填空格，打出去造句 |
| 功能牌 | 一次性干扰/增益效果（强制约束、交换手牌、偷牌、弃牌等） |
| 装备/状态牌 | 持续效果（如"本局所有形容词牌+2紊乱度"） |

### 2.2 填词牌数据模型

```
字段            说明
─────────────────────────────
id, 名称        基本标识
卡牌类型         "fill" / "function" / "equipment"
稀有度          影响出现概率
词性约束        名词/动词/形容词/副词/介词/连词/叹词/无约束
句子成分约束    主语/谓语/宾语/定语/状语/补语/无约束
扩展内容约束    颜色/动物/情感/动作/自然/人体/器物/抽象/时间/空间/.../无约束
基础紊乱值      卡牌自带基础分（约束越窄值越高）
```

### 2.3 约束枚举

**词性：** 名词、动词、形容词、副词、介词、连词、叹词、无约束

**句子成分：** 主语、谓语、宾语、定语、状语、补语、无约束

**扩展内容：** 颜色、动物、情感、动作、自然、人体、器物、抽象、时间、空间、无约束（可扩展）

三类约束均支持"无约束"，即万能牌。约束越多越窄 → 基础紊乱值越高（难填但收益大），反之越低（灵活但收益小）。

### 2.4 法力消耗

由字数动态计算：

```
cost = base_cost + floor(字数 × 每字系数)
例：base_cost=0, 系数=1 → "龙"=1费, "深红色的"=4费
```

## 3. 造句系统

### 3.1 操作流程

1. 查看手牌 + 当前法力值
2. 选择要打出的牌，拖入造句槽
3. 系统按成分自动排序（定→主→状→谓→补→宾），玩家可手动调整顺序构造不同修辞效果
4. 为每张牌填入符合约束的词语
5. 实时显示法力消耗预览
6. 确认出牌 → 消耗法力

### 3.2 句型决定

无预设模板。玩家打出什么成分的牌就构成什么句型。系统提供基本语法提示（如缺主语时高亮主语槽位）。

### 3.3 结构校验

- 最低要求：至少含有主语 + 谓语
- 无非法成分重复
- 不通过 → 记录违规项，在评分中扣百分比
- 出牌不受限制，校验结果作为惩罚项加入评分

## 4. 评分引擎

### 4.1 总体公式

```
总分 = (紊乱度 × 连击倍率 × 修辞加成 - 违规惩罚) × 成分攻防分配
```

所有因子对玩家可见可计算，确保博弈深度。

### 4.2 紊乱度 (0-100)

```
紊乱度 = Σ(每张牌基础紊乱值) / 牌数        (规则引擎)
       + 词嵌入搭配分                         (词嵌入模型)
```

**词嵌入搭配分：** 计算相邻词的 cosine similarity。
- 高相似度（"温暖的 阳光"）→ 低紊乱（合规方向）
- 低相似度（"燃烧的 冰箱"）→ 高紊乱（荒诞方向）

### 4.3 连击倍率

```
连击倍率 = 1.0 + (句子长度 - 2) × 0.2
上限 2.0x
例：3牌=1.2x, 5牌=1.6x
```

### 4.4 修辞加成（可叠加）

| 修辞 | 检测规则 | 倍率 |
|------|---------|------|
| 排比 | 同成分连续出现 ≥3 | ×1.3 |
| 对仗 | 成分对称分布 | ×1.5 |
| 押韵 | 词尾韵母相同 | ×1.2 |
| 无修辞 | — | ×1.0 |

### 4.5 违规惩罚

- 缺少主语或谓语：-20%
- 成分非法重复：-15% 每种

### 4.6 成分攻防分配

按牌数占比分配总分：

| 组别 | 成分 | 映射效果 |
|------|------|---------|
| 攻击组 | 谓语/宾语/补语 | → ATK |
| 防御组 | 主语/定语 | → DEF |
| 修饰组 | 状语 | → CRT（暴击概率） |

```
最终 ATK = 总分 × 攻击组占比
最终 DEF = 总分 × 防御组占比
最终 CRT = 总分 × 修饰组占比
```

### 4.7 技术方案

- **规则引擎：** Godot GDScript（结构分、修辞检测、违规、成分分配）
- **词嵌入模型：** fastText 中文模型（语义搭配分），本地打包

## 5. 战斗系统

### 5.1 结算

| 输出 | 效果 |
|------|------|
| ATK | 扣对方 HP（受对方 DEF 减免） |
| DEF | 获得护盾，持续到本玩家下回合开始 |
| CRT | 暴击概率，触发时 ATK ×1.5 |
| 治疗 | 本方 HP += DEF × 0.5 |

### 5.2 初始数值

- HP: 30
- 法力上限: 10（每回合 +1，从 0 开始）
- 法力每回合回满

## 6. 回合与构筑

### 6.1 回合流程

```
1. 回合开始 → 法力+1(上限10)，法力回满，抽牌
2. 主要阶段 → 选牌 + 填词 + 可打功能/装备牌
3. 评分阶段 → 结构校验 → 规则分 + 语义分 → 战斗数值
4. 结算阶段 → 攻击/防御/暴击/治疗生效
5. 局内事件 → 每N回合触发商店/奖励/诅咒
6. 回合结束 → 切换对手回合
```

### 6.2 局内事件

| 事件 | 频率 | 内容 |
|------|------|------|
| 商店 | 每 3 回合 | 用法力购买新牌加入牌组 |
| 奖励 | 每 2 回合 | 三选一获得新牌 |
| 诅咒 | 每 5 回合 | 强制加入一张负面牌 |

### 6.3 构筑系统

- **局内构筑（爬塔模式）：** 多场连续对战，每场后获得奖励，失败从头开始
- **局前构筑（账号成长）：** 账号级别卡牌收集，随等级解锁，影响局内起始卡组

## 7. AI 系统

### 7.1 Demo 版（规则 + 词嵌入）

三层决策：

1. **策略层** — 评估 HP 差距 → 决定激进(高攻)/保守(高防)/平衡
2. **选牌层** — 过滤可负担牌 → 按策略排序候选 → 词嵌入评估预期紊乱度 → 选出最优组合
3. **填词层** — 按约束过滤词库 → 激进选低相似度词(高紊乱) / 保守选高相似度词(高合规)

难度梯度：
- 简单：随机从合法选项中选
- 普通：按策略选，不追求修辞
- 困难：全面优化，主动追求修辞加分

### 7.2 目标版（LLM 驱动）

将策略层和填词层替换为 LLM 调用，手牌 + 局势 + 策略目标 → 选牌 + 填词方案。预留接口。
