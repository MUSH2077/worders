# 手动测试清单

**最后更新：** 2026-05-27
**用法：** 每次改代码后跑一遍，`[ ]` → `[x]` 通过。

---

## 一、启动与手牌 (4项)

- [ ] 游戏启动无报错，控制台显示 "Player turn: 玩家"
- [ ] 手牌区显示卡牌（紫色圆角面板）
- [ ] 每张卡牌显示：名称、词性、成分、扩展内容、紊乱值
- [ ] 对手手牌区显示卡背

---

## 二、拖拽出牌 (5项)

- [ ] 从手牌拖拽卡牌时出现半透明预览
- [ ] 卡牌拖入造句区成功放入
- [ ] 造句区为空时显示"< 将手牌拖入此处 >"
- [ ] 放入卡牌后自动弹出填词对话框
- [ ] 对话框正确显示约束信息

---

## 三、填词与法力 (4项)

- [ ] 输入词语确认后造句槽显示填入的词
- [ ] 法力消耗预览更新（字数=法力消耗）
- [ ] 点击造句槽可重新填词
- [ ] 多次拖入法力消耗正确累加

---

## 四、出招与评分 (4项)

- [ ] 至少填完主语+谓语后可点击"确认出招"
- [ ] 评分显示 ATK/DEF/CRT/紊乱度/连击倍率
- [ ] 对手HP正确减少
- [ ] 修辞触发时评分显示标签（排比/对仗/押韵）

---

## 五、AI回合 (3项)

- [ ] 玩家出招后自动切换到AI回合
- [ ] 控制台显示 "AI turn: AI"
- [ ] AI自动造句出招，结束后回到玩家回合

---

## 六、状态栏 (3项)

- [ ] 玩家HUD显示 ❤️🛡️⚡🎴 全部更新
- [ ] 对手HUD显示 ❤️⚡🎴 全部更新
- [ ] 每回合法力+1，HP/护盾随战斗变化

---

## 七、游戏结束 (2项)

- [ ] HP≤0时显示 "游戏结束! [胜者] 获胜!"
- [ ] 确认出招按钮被禁用

---

## 八、边界情况 (5项)

- [ ] 法力不足时无法确认出招
- [ ] 造句槽为空时点击确认无反应
- [ ] 牌库抽空后不再抽牌
- [ ] 快速连续拖入多张卡牌不崩溃
- [ ] 牌库耗尽后游戏正常继续

---

**总计：30 项**
