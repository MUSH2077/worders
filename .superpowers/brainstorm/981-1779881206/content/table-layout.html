牌桌布局方案对比

深色=牌桌底色，拖拽出牌→造句槽→出招

A

传统对弈式（上下对称）

己方区在下，对手区在上，中间是双方造句区。经典卡牌游戏布局。

┌─ AI对手 ❤30 🛡0 ──────────┐
│ AI手牌: 🂠🂠🂠🂠 │
├─ 对手造句: [___][___][___] ─┤
│ ⚔️ 牌桌 ⚔️ │
├─ 你的造句: [___][___][___] ─┤
│ 你的手牌: 🂠🂠🂠🂠 │
└─ 你 ❤30 🛡0 ⚡1 ──────────┘
B

牌桌沉浸式（左中右三栏）⭐推荐

左右两侧状态栏+头像，中间大面积牌桌区域放手牌和造句槽。

┌─左─┐ ┌────── 中央牌桌 ──────┐ ┌─右─┐
│AI │ │ 对手造句: [__][__][__] │ │你 │
│头像 │ │ │ │头像 │
│❤30 │ │ 你的造句区 │ │❤30 │
│🛡0 │ │ [定:___][主:___] │ │🛡0 │
│⚡10 │ │ │ │⚡1 │
│🎴15 │ │ 🂠🂠🂠🂠 (你的手牌) │ │🎴14 │
└────┘ └──────────────────────┘ └────┘
C

聚焦式（手牌区放大+悬浮HUD）

手牌占主体面积，状态栏悬浮边角，适合小屏幕。

[AI ❤30]─────────────┐
│ 造句: [___][___] │
│ │
│ 🂠 🂠 🂠 🂠 │ ← 大手牌区
│ │
└─────────────[你 ❤30]

美化路线图（分阶段）

Phase 1 - 基础可用： StyleBoxFlat 面板 + 基础配色（当前已完成）
Phase 2 - 牌桌成型： 方案B三栏布局 + 桌布纹理 + 头像占位 + 状态栏图标
Phase 3 - 视觉打磨： 卡牌动画（拖拽/打出/翻转）+ 粒子特效 + 音效
Phase 4 - 完整美术： 定制卡牌原画 + 专属桌布 + 角色立绘 + UI动效
